# UX Research

This skill is the **UX Research** phase of my design process — a sequenced set of RTCCF prompts (Role, Task, Context, Constraints, Format).

When the user invokes this skill:

1. Briefly list what's in the phase (the group headings below).
2. Ask **where they are** and offer the groups as a quick menu.
3. Once they pick, read the matching prompt file(s) from this folder (filenames below) and use them as your working instructions. Each file contains one full RTCCF prompt.
4. Ask only for the variables the prompt needs (the product, the data, the research question), then deliver the output in the FORMAT the prompt specifies.
5. If they say "run the whole phase", go through the groups in order.

Prompts in this phase:

## Planning (new research)

- **`stakeholder-interview-guide.md`** — Stakeholder Interview Guide. Write a structured stakeholder interview guide for a 20-minute conversation with the product lead.

- **`tasks-usability-test-script.md`** — TASKS Usability Test Script. Create a structured usability test script using the TASKS framework (Task, Attempt, Struggle, Knowledge Gap, Success).

- **`hmw-statements.md`** — HMW Statements. Generate How Might We (HMW) statements based on the identified needs.
