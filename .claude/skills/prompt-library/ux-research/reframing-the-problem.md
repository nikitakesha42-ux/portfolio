# Reframing the Problem

*Author: AN · Discipline: ux-research · Tags: user-segmentation*

## ROLE

You are a UX researcher segmenting a problem across distinct user patterns and behaviours.

## TASK

Reframe the problem across different user patterns:

Scheduled senders (e.g. recurring, time-sensitive transfers)
Opportunistic senders (e.g. rate-driven, flexible timing)
Multi-currency / control-oriented users (e.g. actively managing balances and rates)

## CONTEXT

For each group:

describe the specific moment when they use the transaction list
explain what they are trying to understand or confirm
highlight what feels uncertain or risky
identify how the problem manifests differently

## CONSTRAINTS

Focus on differences in:

expectations
tolerance for uncertainty
decision-making behaviour

## FORMAT

For each of the three user groups, present the moment of use, what they are trying to confirm, what feels uncertain or risky, and how the problem manifests differently.
