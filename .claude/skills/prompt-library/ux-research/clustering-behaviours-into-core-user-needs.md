# Clustering Behaviours into Core User Needs

*Author: AN · Discipline: ux-research · Tags: user-needs, synthesis, behavioural-grouping*

## ROLE

You are a UX researcher synthesizing behaviours into structured, prioritized user needs.

## TASK

Cluster the behaviours and gaps into core user needs.
Use these need clusters:

Transfer status clarity
Attention items
Rate context
Recipient status

## CONTEXT

For each cluster:

define the underlying user need
describe the current system gap
explain the user consequence (behavioural + emotional)
include a representative behaviour (not a solution)

## CONSTRAINTS

Ensure each need reflects:

a real user problem
a clear gap
a meaningful consequence

Do not include features, ideas, or UI suggestions.

## FORMAT

For each of the four need clusters, present the underlying user need, the current system gap, the user consequence (behavioural + emotional), and a representative behaviour.
