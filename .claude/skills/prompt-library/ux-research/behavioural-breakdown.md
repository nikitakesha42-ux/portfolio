# Behavioural Breakdown

*Author: AN · Discipline: ux-research · Tags: user-behaviour, triggers*

## ROLE

You are a UX researcher mapping a problem into concrete, observable user behaviours.

## TASK

Break the problem into observable user behaviours.
For each behaviour:

what triggers the behaviour
what the user is trying to understand
what information they rely on in the transaction list
where the list falls short
what workaround (if any) they use instead

## CONTEXT

Focus on behaviours such as:

checking status immediately after sending
returning multiple times to check progress
confirming arrival with the recipient
tracking expected amounts or timing
identifying delays, holds, or issues

## CONSTRAINTS

Be specific about user actions (e.g. "opens transfer", "messages recipient", not "checks status").
Avoid abstraction — describe concrete actions.

## FORMAT

For each behaviour, present its trigger, what the user is trying to understand, the information they rely on, where the list falls short, and the workaround they use instead.
