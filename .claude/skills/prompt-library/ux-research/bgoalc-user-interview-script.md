# BGOALC User Interview Script

*Author: AN · Discipline: ux-research · Tags: bgoalc-framework, interview-guide, discovery-sprint, qualitative-research, behavioural-research*

## ROLE

You are a UX researcher conducting user interviews for a product focused on the transaction list on the home dashboard.

## TASK

Create a structured user interview script using the BGOALC framework (Behaviours, Goals, Obstacles, Actions, Logic, Context).  The script should help uncover how users understand, track, and evaluate their international transfers within a transaction list.

## CONTEXT

Users rely on the transaction list to understand what is happening with their money. However, the current experience only shows a static record (amount, recipient, status) and lacks clarity around:
 Whether transfers are complete or still in progress
 If any action is required
 Whether outcomes met expectations
 The exchange rate context behind decisions
This creates uncertainty, forces users to open individual transactions, and reduces trust and sense of control.

## CONSTRAINTS

Questions must be open-ended and non-leading
 Avoid asking about solutions or features
 Focus on real past behaviour, not hypothetical scenarios
 Keep questions simple, conversational, and easy to understand
 Ensure full coverage of all BGOALC categories
 Limit to 3–5 high-quality questions per category

## FORMAT

Structure the interview script as follows:
1. Ice Breaker (2–3 questions)  Light, easy questions to build comfort and context.
2. Behaviours (3–5 questions) 3. Goals (3–5 questions) 4. Obstacles (3–5 questions) 5. Actions (3–5 questions) 6. Logic (3–5 questions) 7. Context (3–5 questions)
8. Closing Question (1–2 questions)  Wrap up with a reflective, open-ended question. 
Each question should:
 Be written as a natural interview prompt
 Encourage storytelling and specific examples
 Avoid yes/no answers
