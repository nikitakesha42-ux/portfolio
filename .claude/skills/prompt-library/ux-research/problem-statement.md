# Problem Statement

*Author: AN · Discipline: ux-research · Tags: discovery-sprint, synthesis, user-behaviour, insight-framing*

## ROLE

You are a senior UX researcher synthesizing discovery research into a sharp, evidence-based problem statement.

## TASK

Write a clear, evidence-based problem statement for a discovery sprint focused on the transaction list on the home dashboard.

## CONTEXT

The transaction list is a high-frequency surface used by people who send money internationally.

Users return to this list after sending to:
- check whether money has arrived
- understand the status of transfers
- decide whether they need to take action

Research indicates that:
- users revisit the list multiple times after sending
- they rely on workarounds (e.g. screenshots, messaging recipients, manual tracking)
- the list shows what happened, but does not consistently communicate:
  - what it means
  - what is still in progress
  - whether any action is required

## CONSTRAINTS

- Do not propose solutions, features, or UI changes
- Do not restate the context — focus on synthesis and insight
- Do not introduce assumptions not grounded in observed behaviour
- Avoid vague or generic phrases (e.g. “improve clarity”, “enhance experience”)

The problem statement must:
- be grounded in observable user behaviour, not inferred intent
- make the gap explicit (what users need vs what the system shows)
- articulate consequences:
  - behavioural (e.g. repeated checking, opening transfers, contacting support)
  - emotional (e.g. uncertainty, anxiety, reduced sense of control)
- reflect that this is an active decision-making surface, not a passive history

## FORMAT

Write 2–3 concise paragraphs that:
1. Define the user group and the moment of use
2. Describe the gap between current system behaviour and user needs
3. Explain the consequences of this gap on behaviour, confidence, and decision-making

Where possible, anchor statements in concrete behaviours rather than abstractions.
