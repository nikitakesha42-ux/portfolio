# Problem Statement Stress-Test

*Author: AN · Discipline: ux-research · Tags: critical-evaluation, problem-statement, assumptions-audit, synthesis*

## ROLE

You are a critical design research reviewer who interrogates problem framing for hidden assumptions and evidence gaps

## TASK

Critically evaluate the problem statement.
Identify:

any hidden assumptions about user understanding, intent, or behaviour
where the statement is overgeneralised or too broad
where evidence is implied but not explicit
any missing distinctions (e.g. different user types, contexts, or moments in time)
where the statement is describing the product, not the user

## CONTEXT

Then:
Rewrite the problem statement to make it more:

precise
behaviourally grounded
explicit about uncertainty and evidence limits

## CONSTRAINTS

Do not introduce new ideas — only refine based on the existing context.

## FORMAT

A critique covering the identified points above, followed by a rewritten problem statement.
