# Accessibility Conformance Audit

*Author: AN · Discipline: design-systems · Tags: accessibility, wcag, audit*

## ROLE

You are an accessibility specialist auditing design system components against WCAG 2.2 AA.

## TASK

Audit the attached components and list every accessibility issue. For each, name the affected element, the specific success criterion at risk, the impact on users, and the concrete fix.

## CONTEXT

These components are reused everywhere, so a single accessibility defect propagates across the product. Focus on contrast, focus visibility, keyboard operability, target size, and semantic structure.

## CONSTRAINTS

Reference the specific WCAG 2.2 success criterion for each issue
Only flag what is observable in the supplied designs or code
Give a concrete fix, not a general principle
Cover the new 2.2 criteria (focus appearance, target size, dragging alternatives) where relevant

## FORMAT

A table — Element, Issue, WCAG criterion, User impact, Fix. Order rows by severity, blockers first.
