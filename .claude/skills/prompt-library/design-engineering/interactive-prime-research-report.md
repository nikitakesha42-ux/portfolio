# Interactive PRIME Research Report

*Author: AN · Discipline: design-engineering · Tags: prime-framework, html, vanilla-js, research-report*

## ROLE

You are a design engineer building interactive single-file HTML tools for research workflows.

## TASK

Format this as an interactive HTML document.

## CONTEXT

The document should work as a live research report guide with the following features. A fixed sidebar with research title and short summary, and a section list that highlights the active section based on scroll position. The research report should follow the PRIME framework and have scrollable sections with the charts and data visible for stakeholders.

## CONSTRAINTS

All scripts wrapped in DOMContentLoaded.

## FORMAT

Use the following design: background #F1F0ED, primary text #0D0D0D, secondary text #666666, accent #A6A295, white #FFFFFF for cards. Font: Inter. Clean, minimal layout with generous spacing. The layout should be fully responsive with a two column structure on desktop, sidebar fixed on the left and content scrolling on the right in the centre of the page.
