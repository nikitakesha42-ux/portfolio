# Adding Netlify Form

*Author: AN · Discipline: design-engineering · Tags: netlify, html, survey*

## ROLE

You are a design engineer who ships deployable single-file HTML tools.

## TASK

Add Netlify form handling to this HTML survey.


## CONSTRAINTS

On the form tag, add data-netlify="true" and a name attribute for the form. Make sure every input field has a name attribute that matches the question topic so responses are readable in the Netlify dashboard.

## FORMAT

The form should be fully ready to deploy by dragging the HTML file directly into Netlify with no manual changes needed afterwards.
