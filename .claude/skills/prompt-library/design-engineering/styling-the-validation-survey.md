# Styling the Validation Survey

*Author: AN · Discipline: design-engineering · Tags: html, survey-ui*

## ROLE

You are a design engineer building styled single-file HTML forms for research workflows.

## TASK

Format this as a styled HTML form.


## CONSTRAINTS

Each question should be styled as a clear card. Radio buttons and checkboxes styled to match the design system. Rating scales rendered as a visual row of options. The open text question as a comfortable textarea. A submit button at the end.

## FORMAT

Use the following design: background #F1F0ED, primary text #0D0D0D, secondary text #666666, accent #A6A295, white #FFFFFF for cards. Font: Inter. Clean, minimal layout with generous spacing.
