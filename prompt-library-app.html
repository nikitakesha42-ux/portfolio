Sync across devices

Sync is off. Add your Gist ID and a token to turn it on.

The 32-character ID from the Gist URL. Create one at gist.github.com with a file named prompts.json.
Needs the gist scope only. Create one at github.com/settings/tokens (classic) or github.com/settings/personal-access-tokens (fine-grained). Stored only in your browser.
How does this work?
One file in your Gist (prompts.json) holds the whole library.
• Every edit here pushes to the Gist after a 1-second pause.
• Every launch pulls the Gist first, then renders.
• Last writer wins — if you edit two devices offline at the same time, the newer save overwrites the older one on next sync.
• Credentials never leave your browser except to api.github.com.
